# Реализация главной страницы и компонентов

## Что было сделано

### 1. Установлены зависимости
- ✅ React Router DOM v7 - для маршрутизации
- ✅ Tailwind CSS v3 - для стилизации
- ✅ PostCSS и Autoprefixer - для обработки CSS

### 2. Создана главная страница (HomePage)
Главная страница состоит из модульных компонентов:

#### Компоненты главной страницы:
- **Hero** (`src/components/home/Hero.tsx`) - Главный баннер с призывом к действию
- **Features** (`src/components/home/Features.tsx`) - Преимущества магазина
- **FeaturedProducts** (`src/components/home/FeaturedProducts.tsx`) - Популярные товары
- **CallToAction** (`src/components/home/CallToAction.tsx`) - Призыв к действию

### 3. Обновлен Header
Полнофункциональный Header включает:
- Логотип с анимацией
- Навигационное меню (Главная, Каталог, О нас, Контакты)
- Поиск по товарам
- Иконка корзины с счетчиком
- Иконка профиля
- Мобильное меню (бургер-меню)
- Sticky позиционирование

### 4. Обновлен Footer
Расширенный Footer содержит:
- Информация о компании
- Навигационные ссылки
- Контактная информация (телефон, email, адрес)
- Социальные сети (Instagram, Facebook, VK)
- Копирайт и юридические ссылки
- Время работы

### 5. Настроен роутинг
Реализованы маршруты для всех страниц:
- `/` - Главная страница
- `/catalog` - Каталог товаров
- `/product/:id` - Страница товара
- `/cart` - Корзина
- `/checkout` - Оформление заказа
- `/profile` - Личный кабинет
- `/admin` - Админ панель
- `/about` - О компании
- `/contacts` - Контакты
- `*` - 404 страница

### 6. Создан Layout компонент
Обновленный Layout обеспечивает:
- Единую структуру для всех страниц
- Header вверху
- Footer внизу
- Растягивающийся main контент

### 7. Дополнительные страницы
Созданы страницы:
- **AboutPage** - Информация о компании
- **ContactsPage** - Контактная информация и форма обратной связи

## Дизайн

### Стиль
Элегантный и премиальный дизайн с:
- Градиентами
- Плавными анимациями
- Тенями и эффектами hover
- Адаптивной версткой

### Цветовая палитра
- **Primary** (розовые оттенки) - для акцентов и CTA
- **Elegant** (бежевые оттенки) - для фонов и дополнительных элементов
- **Gray** - для текста и нейтральных элементов

### Типографика
- **Playfair Display** - для заголовков (serif)
- **Inter** - для основного текста (sans-serif)

## Структура файлов

```
src/
├── components/
│   ├── home/                    # Компоненты главной страницы
│   │   ├── Hero.tsx            # Hero секция
│   │   ├── Features.tsx        # Преимущества
│   │   ├── FeaturedProducts.tsx # Популярные товары
│   │   └── CallToAction.tsx    # Призыв к действию
│   └── layout/                  # Layout компоненты
│       ├── Header.tsx          # Шапка сайта
│       ├── Footer.tsx          # Подвал
│       └── Layout.tsx          # Общий layout
├── pages/
│   ├── HomePage.tsx            # Главная страница
│   ├── AboutPage.tsx           # О компании
│   ├── ContactsPage.tsx        # Контакты
│   ├── CatalogPage.tsx         # Каталог (заглушка)
│   ├── CartPage.tsx            # Корзина (заглушка)
│   ├── ProfilePage.tsx         # Профиль (заглушка)
│   └── index.ts                # Экспорты
├── App.tsx                      # Роутинг
└── index.css                    # Tailwind + глобальные стили
```

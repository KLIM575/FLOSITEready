# 🌸 Flower Shop - Интернет-магазин цветов

Современный интернет-магазин цветов, построенный на React + TypeScript + Vite.

## Возможности

### Для покупателей
- 📦 **Каталог товаров** - просмотр всех доступных цветов и букетов
- 🌹 **Карточки товаров** - детальная информация о каждом товаре
- 🛒 **Корзина** - добавление товаров и управление заказом
- 💳 **Оформление заказа** - форма доставки и оплаты
- 👤 **Личный кабинет** - профиль пользователя и история заказов

### Для администраторов
- ⚙️ **Админ панель** - управление товарами и заказами
- ➕ **Добавление товаров** - создание новых позиций
- ✏️ **Редактирование товаров** - обновление информации
- 🗑️ **Удаление товаров** - удаление позиций из каталога

## Технологический стек

- **Frontend**: React 19 + TypeScript
- **Build Tool**: Vite 8
- **State Management**: React Context API
- **Styling**: Tailwind CSS v3
- **Routing**: React Router v7
- **API**: REST API (планируется backend)

## Структура проекта

```
src/
├── components/       # React компоненты
│   ├── common/      # Переиспользуемые компоненты
│   ├── layout/      # Layout компоненты
│   ├── catalog/     # Компоненты каталога
│   ├── cart/        # Компоненты корзины
│   ├── checkout/    # Компоненты оформления
│   ├── profile/     # Компоненты профиля
│   └── admin/       # Компоненты админки
├── pages/           # Страницы приложения
├── context/         # React Context
├── hooks/           # Custom hooks
├── services/        # API сервисы
├── types/           # TypeScript типы
├── utils/           # Утилиты
├── constants/       # Константы
└── styles/          # Глобальные стили
```

Подробная документация структуры: [PROJECT_STRUCTURE.md](./PROJECT_STRUCTURE.md)

## Установка и запуск

```bash
# Установка зависимостей
npm install

# Запуск dev сервера
npm run dev
# Откройте http://localhost:5174 в браузере

# Сборка для production
npm run build

# Предпросмотр production сборки
npm run preview
```

# Реализованные функции товаров

## Что было добавлено

### 1. Система размеров товаров (S, M, L, XL)
- Добавлена поддержка различных размеров для букетов
- Каждый размер имеет свою цену
- S - 15-25 цветов
- M - 25-35 цветов
- L - 35-50 цветов
- XL - 50+ цветов

### 2. Страница товара (`/product/:id`)
Полностью функциональная страница товара включает:
- **Галерея изображений** - основное изображение и миниатюры
- **Информация о товаре** - название, категория, описание, цена
- **Выбор размера** - интерактивные кнопки для выбора размера с отображением цены
- **Количество** - счетчик с кнопками +/- для выбора количества
- **Динамический расчет цены** - автоматический пересчет при изменении размера/количества
- **Две кнопки действий**:
  - "Купить в 1 клик" - мгновенный переход на страницу оформления заказа
  - "Добавить в корзину" - добавление товара с уведомлением
- **Информация о доставке** - условия доставки и гарантии
- **Breadcrumbs навигация** - хлебные крошки для удобной навигации
- **Статус наличия** - индикатор наличия товара

### 3. Страница оформления заказа (`/checkout`)
Двухэтапный процесс оформления:

#### Шаг 1: Информация о доставке
- Форма с полями: имя, телефон, email, город, индекс, адрес
- Комментарий к заказу
- Валидация обязательных полей

#### Шаг 2: Оплата по QR-коду
- **QR-код для оплаты** - визуальный QR-код с суммой заказа
- **Инструкции по оплате** - пошаговое руководство
- **Поддерживаемые банки** - Сбербанк, Тинькофф, Альфа-Банк, СБП
- **Страница успешного заказа** - подтверждение с деталями доставки

### 4. Обновленная корзина (`/cart`)
- Отображение всех товаров с изображениями
- Размер товара (если выбран)
- Изменение количества для каждого товара
- Удаление товаров из корзины
- Расчет стоимости доставки (бесплатно от 5000 ₽)
- Кнопка "Очистить корзину"
- Информация о преимуществах магазина

### 5. Улучшенная карточка товара
- Современный дизайн в стиле проекта
- Отображение цены "от X ₽" для товаров с размерами
- Кнопка "В корзину" на карточке
- Hover эффекты и анимации
- Статус наличия товара

### 6. Обновленный каталог (`/catalog`)
- Фильтрация по категориям
- Поиск по названию и описанию
- Отображение всех товаров с использованием ProductCard
- Сброс фильтров

### 7. Контекст корзины (CartContext)
Улучшенная логика:
- Поддержка размеров товаров
- Уникальные элементы корзины по ID товара + размер
- Правильный расчет цены с учетом размера
- Счетчик общего количества товаров
- Методы: addToCart, removeFromCart, updateQuantity, clearCart, getTotalPrice, getItemCount

### 8. Типы данных
Обновлены TypeScript типы:
- `ProductSize` - тип для размеров (S, M, L, XL)
- `ProductSizePrice` - интерфейс для цены размера
- `Product` - добавлены поля sizes, images
- `CartItem` - добавлено поле size

### 9. Тестовые данные
Создан файл `src/data/products.ts` с 6 товарами:
1. Букет роз "Романтика"
2. Композиция "Весна"
3. Букет тюльпанов "Нежность"
4. Орхидея в горшке
5. Букет пионов "Роскошь"
6. Подарочный набор "Премиум"

## Дизайн
Все компоненты выполнены в едином стиле:
- Цветовая палитра: primary (розовый) и elegant (бежевый)
- Шрифты: Playfair Display (заголовки), Inter (текст)
- Rounded углы, тени, hover эффекты
- Градиентные фоны
- Адаптивный дизайн

## Как использовать

1. Запустите сервер: `npm run dev`
2. Откройте http://localhost:5175
3. Перейдите в каталог
4. Выберите товар
5. Выберите размер (если доступно)
6. Добавьте в корзину или купите в 1 клик
7. Оформите заказ
8. Оплатите по QR-коду
